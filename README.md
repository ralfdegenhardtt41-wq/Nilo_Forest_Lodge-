# Nilo Forest Lodge — website

Static site built with [Astro](https://astro.build), deployed to GitHub Pages via `.github/workflows/deploy.yml`.

- `npm install` — install dependencies
- `npm run dev` — local dev server
- `npm run build` — build to `dist/`

Content lives in `src/pages/*.astro`, shared facts (email, phone, coordinates) in `src/site.ts`, images in `src/assets/images/`.
